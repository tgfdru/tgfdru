## 🩺 AI for Digital Health

### [ResistAI Sentinel](https://github.com/tgfdru/ResistAI-Sentinel-BMC-DIGITAL-HEALTH)
Explainable clinical decision support for **early Antimicrobial Resistance (AMR) risk detection**. It combines a rule-based clinical score, a Random Forest risk classifier and clinical-note NLP flags, in a 6-view Streamlit dashboard: hospital heatmap, early-warning trend, what-if simulator, spread risk, explainable AI and an executive PDF report.
`scikit-learn` `Streamlit` `Plotly` `Explainable AI`

### [Facial Emotion Recognition](https://github.com/tgfdru/facial-emotion-recognition)
A from-scratch PyTorch CNN that classifies five facial expressions, with **Grad-CAM** explainability and a live webcam demo.
`PyTorch` `Computer Vision` `Grad-CAM` `Gradio`

## 🗣️ Arabic NLP & LLM Systems

### [NABIQ: Arabic Function Calling](https://github.com/tgfdru/nabiq-arabicfc) · [📄 Paper](https://aclanthology.org/2026.arabicnlp-sharedtasks.201/)
A fully classical, CPU-only pipeline (no LLMs, no GPUs) for the AISA-ArabicFC shared task across five Arabic dialects. **91.4% function accuracy** on the official blind test, above the fine-tuned baseline on Track B.
`TF-IDF` `Logistic Regression` `Retrieval` `ACL 2026`

### [Saudi Legal RAG](https://github.com/tgfdru/saudi-legal-rag) · [🤗 Demo](https://huggingface.co/spaces/tgfdru/saudi-legal-rag)
Everyday Arabic legal questions → the Saudi-law article that answers them, with citations. Covers 1,474 articles from 11 laws. bge-m3 + cross-encoder reranking reaches **R@5 = 0.96**.
`RAG` `bge-m3` `Reranking` `Gradio` `FastAPI`

### [Mu'een (مُعين الداعية)](https://github.com/tgfdru/hikmah-dev): team project
A source-backed RAG assistant integrated into the Sheykak mobile app. **I built the agent and API layer**: routing, an independent judge, the reply-language resolver and deployment.
